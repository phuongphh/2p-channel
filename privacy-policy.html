01 — Overview

Overview

This Privacy Policy describes how 2P Channel ("we", "our", or "us") collects, uses, and handles information in connection with our content publishing automation tool. This tool is a personal-use application designed to automatically publish daily news videos to the operator's own TikTok account.

Important notice This application is operated solely for personal content publishing purposes. It is not a public-facing product or service. No user accounts are created and no third-party personal data is collected or processed.
02 — Information We Collect

Information We Collect

Given the personal-use nature of this application, the data collected is minimal and limited to what is necessary to operate the service:

  • TikTok OAuth access tokens required to authenticate and publish content on the operator's behalf
  • Video metadata (title, description, hashtags) provided by the operator for each post
  • Technical logs for debugging purposes (timestamps, API response codes)

We do not collect any personal information from third parties, viewers, or followers of the TikTok channel.

03 — How We Use Information

How We Use Your Information

The information collected is used exclusively to:

  • Authenticate with TikTok's API on behalf of the channel operator
  • Schedule and automatically publish video content to the operator's TikTok account
  • Monitor upload status and handle errors in the automation workflow

No data is used for advertising, analytics, or shared with any third party for commercial purposes.

04 — TikTok Integration

TikTok Integration

This application integrates with the TikTok Content Posting API using the video.publish scope. This scope grants the application permission to upload videos directly to the operator's TikTok account.

Scope used video.publish — Allows posting videos to the authenticated TikTok account. No other scopes are requested or used.

Access tokens issued by TikTok are stored securely and are used solely for the purpose of publishing content. These tokens are never shared with any external party.

Our use of TikTok's API is subject to TikTok's Privacy Policy and TikTok Developer Terms of Use.

05 — Data Sharing

Data Sharing

We do not sell, trade, or rent any information to third parties. Data is shared only in the following limited circumstances:

  • With TikTok's platform as required to publish content via their API
  • If required by applicable law, regulation, or legal process
06 — Data Retention

Data Retention

TikTok access tokens are retained only as long as necessary to maintain the publishing automation workflow. Tokens are deleted or revoked when no longer needed, or upon request.

Technical logs are retained for a maximum of 30 days for debugging purposes and are then permanently deleted.

07 — Your Rights

Your Rights

As this is a personal-use tool, the only data subject is the operator of this application. As the operator, you have the right to:

  • Access any data stored by this application at any time
  • Request immediate deletion of all stored tokens and logs
  • Revoke TikTok API access at any time via TikTok's developer portal
08 — Security

Security

We take reasonable technical measures to protect stored credentials and tokens, including environment variable storage and access control on server infrastructure. However, no method of electronic storage is 100% secure.

09 — Changes to This Policy

Changes to This Policy

We may update this Privacy Policy from time to time. Any changes will be reflected on this page with an updated effective date. Continued use of the application after changes constitutes acceptance of the revised policy.
